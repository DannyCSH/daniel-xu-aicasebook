# AI 产品案例册

> 把 AI 织进真实工作流。

许哲安 · AI 产品经理。这个仓库收录我在 AI 产品方向上的案例与拆解——重点不在于「用了什么模型」，
而在于**怎么把模糊的 AI 想法变成能跑起来、能验证、有边界的工作流**：从需求拆解到任务定义，
再到模型、数据、规则、工具与人工审核的协同编排，并为失败、权限与反馈设计清晰闭环。
